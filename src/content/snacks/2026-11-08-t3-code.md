Sample snack. T3 Code is a desktop window for coding agents. It does not bring its own model: it drives the Claude Code and Codex installs you already have, and gives each task a thread.

The good part is review. Reading a diff in a proper pane, with the conversation next to it, is calmer than scrolling a terminal. I caught one unwanted change I am fairly sure I would have waved through otherwise.

The part I am unsure about is whether I need a window at all. I live in a terminal, and every time something unusual came up (a hook, a custom command, a strange permission prompt) I ended up back there.

It stays on a branch. If I am still opening it in two weeks it gets merged.
