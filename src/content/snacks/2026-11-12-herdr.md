Sample snack. I had been running coding agents in tmux panes and losing track of them. One would sit on a permission prompt for twenty minutes while I watched another one type.

herdr is a terminal multiplexer that understands agents. Each one gets a row in a sidebar with a state: working, idle, or needs you. That one yellow dot removed most of my tab-switching.

It also detaches like tmux. I start four tasks on the dev box, close the laptop, and attach again later to a summary of what happened. Nothing about it needs a desktop app, which is why it stuck.

The honest downside is me, not the tool. It makes running four agents easy, and I cannot review four agents' work properly. Two is the number where I still read every diff.

Merged, with the limit set to two.
